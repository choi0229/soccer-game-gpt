- Java 21 Docker 빌드: 성공. 도메인 26개, 전략 1개, SQL 초기화 1개 테스트 통과 (총 28개).
- 프론트엔드 TypeScript 타입 검사와 Vite 프로덕션 빌드: 성공.
- `docker compose up --build -d`: PostgreSQL, Spring Boot, Nginx 실행 성공. 로컬 웹 포트는 5187 (5173은 기존 서비스가 사용 중).
- Chromium: 실제 화면에서 48주 전체 시즌 완주, 이벤트 선택, 경기 중계 건너뛰기, 시즌 요약, 새로고침 복원, 로그 재현, 리그 8개교 표시 통과.
- Chromium 390×844: 일과 선택 컨트롤 접근 및 가로 넘침 없음 확인. 브라우저 테스트 2개 통과.
- API 통합: 같은 시드 12345·선택으로 두 시즌(각 445개 행동) 완주. 각 행동 이후 상태 전체 일치, 14개 리그 경기, 최종 로그 재현과 저장된 상태 조회 통과.
- 실제 PostgreSQL: 기존 행을 바꾸지 않는 검증으로 UPDATE/DELETE 금지 및 순번 건너뛰기 거부 통과.
- 같은 판·순번의 동시 요청: 200 / 409로 한 요청만 확정. 이후 재현 결과 일치.
- 최종 밸런스: 이벤트 30편 포함, random/training/balanced 각각 시드 0~999로 1,000시즌 (총 3,000시즌) 실행 성공.
- 밸런스 수치 수정 없음. 세부 분포·주별 체력·관찰은 `balance.md`, `balance.json`에 기록.

## 수치 관찰

- 무작위와 균형의 학업 평균이 각각 99.98, 99.99로 상한에 집중한다. 세 전략 모두 여름·겨울 성적 미달 비율은 0이다. 보충수업 규칙 자체는 별도 경계 테스트에서 검증했다.
- 부상 평균은 무작위 0.066, 훈련 위주 0.026, 균형 0.001회/시즌이다. 저체력 조건과 자동 회복의 조합에서 부상 경로가 드물게 사용된다.
- 훈련 위주의 주력 평균은 75.16으로 가장 높지만 선발 비율은 15.1%로 가장 낮다. 출전 점수는 주력만이 아닌 훈련 능력치 12개의 평균과 감독 관계도를 사용하고, 리그가 18주에 끝나므로 연말의 높은 주력 능력치가 후기 경기에 쓰일 기회가 없다.
- 기본 다크호스에서 세 전략 모두 벤치 비율이 0이다. 시작 감독 관계도 30과 최소 훈련 능력 평균 17.5로도 출전 점수 23.75가 교체 기준 20을 넘는다. 부상이 드물고 리그는 여름방학 전에 끝나, 벤치 경로가 관찰되지 않았다.
- 팀 골/경기는 무작위 1.048, 훈련 위주 0.948, 균형 1.171이다. 포아송 팀 득점에 장면 골·도움·압박 득점을 추가하는 구조를 그대로 적용했다.
